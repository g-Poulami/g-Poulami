# Poulami | Bioinformatics Researcher

Bioinformatics engineer focused on addressing healthcare disparities through "reproducible pipeline engineering" and "ancestry-aware" genomic analysis.

## Featured Project: GenEquityFlow
**[GenEquityFlow](https://github.com/g-Poulami/GenEquityFlow)** is a professional-grade Snakemake pipeline designed to quantify the Generalizability Gap in cancer genomics.

### Core Technical Competencies
| Feature | Implementation |
| :--- | :--- |
| **Automation** | Multi-core Snakemake workflow for "automated end-to-end" processing. |
| **Integrity** | Strict variant filtering (QUAL > 30) and "functional tagging" logic. |
| **Reproducibility** | Standardized Conda environments for "fully traceable" research. |
| **Resilience** | Engineered local annotation workarounds to bypass external server outages. |

### Statistical Impact
The framework automates the comparison of biomarker prevalence between South Asian and European cohorts, providing an audit trail from raw FASTQ reads to final population frequency reports.

## Technical Stack
* **Workflow Management**: Snakemake
* **Genomics**: BWA, BCFtools, Samtools, SnpEff
* **Analysis**: Python (Pandas, Matplotlib, Seaborn)
* **DevOps**: GitHub Actions (CI/CD), Conda
