## 🔬 Featured Projects

### 🧬 [cfDNA-CNV-Pipeline](https://github.com/g-Poulami/cfDNA-CNV-Pipeline)
- **Clinical Liquid Biopsy Workflow**: Developed an end-to-end pipeline for detecting tumor fraction in cell-free DNA using **ichorCNA** and **HMMcopy**.
- **Engineering Highlights**: Automated genomic bin synchronization (1MB resolution) and implemented **GitHub Actions (CI/CD)** for environment validation.
- *Tech: R, ichorCNA, Bash, GitHub Actions*

### 🏥 [Somatic-Variant-Calling-Pipeline](https://github.com/g-Poulami/Somatic-Variant-Calling-Pipeline)
- **NGS Pipeline Engineering**: Built a scalable workflow for detecting somatic mutations in tumor-normal pairs following GATK Best Practices.
- **Engineering Highlights**: Utilized **Nextflow** for orchestration and **Docker** for containerized dependency management.
- *Tech: Nextflow, Docker, GATK, Mutect2, Samtools*

- **Architecture**: Built with Python and Chart.js, featuring live filters and KPI cards for clinical research data.
- *Tech: Python, Chart.js, HTML/CSS*
